The Context

Attendance is a routine process, but in classrooms and similar environments, recording it manually takes valuable time. Traditional methods such as roll calls and paper registers depend heavily on human involvement. This leads to missing entries, incorrect records, duplicate entries, and proxy attendance.

We built an AI-based Face Recognition Attendance System to make this process automated and contactless. The system uses a webcam to capture faces, identifies registered students with a trained recognition model, and records their attendance digitally with the date and time.

The project was developed as a prototype for controlled environments such as classrooms or offices. Its focus was to show how computer vision and machine learning can be applied to attendance management.

The Challenge

The goal was not simply to detect a face. The system had to connect several steps into one reliable workflow:

  • Collect and organize student facial data before recognition can take place.
  • Detect faces from a live webcam feed and compare them with registered data.
  • Identify the student and record attendance without creating duplicate entries.
  • Keep running when no face is detected or an unregistered person appears, and never create an incorrect record.
SituationRequired behaviour
Registered student detectedIdentify the student and mark attendance once
Same student detected againDo not create another record in the session
Unknown faceDo not mark attendance; continue scanning
No face in frameContinue operating without error

Our Approach

We designed the system as a modular pipeline rather than treating attendance as a single operation. Separating data collection, model training, recognition, and attendance management makes each part easier to test and maintain.

The workflow begins with student registration. The administrator enters the student's name and roll number, and the webcam captures multiple facial images. These are stored in folders named by roll number and form the training dataset. Once the dataset is ready, the system trains a recognition model. During attendance, the trained model is loaded to recognize students from the live feed.

The Solution

The system combines face detection, face recognition, attendance logic, and a simple web interface.

ModuleWhat it does
Student RegistrationAdmin enters name and roll number. The webcam captures multiple images. Faces are detected before saving, and images are filed by roll number.
Detection and RecognitionOpenCV detects faces and processes images. The Local Binary Pattern Histogram (LBPH) algorithm links facial images to roll numbers and creates a reusable trained model. Live frames are compared with this model.
Attendance ManagementOn a successful match, the system records name, roll number, date, and time. It checks for duplicates and skips unrecognized faces.
Web InterfaceA Flask dashboard lets the administrator enter details, capture images, start training, and trigger attendance without touching backend code.

How It Works

At a high level, the system follows this flow. During registration, images move from the webcam into the dataset. During attendance, live input is compared with the trained LBPH model, and recognized students are written to a CSV file.

The Outcome

The project showed how facial recognition can replace a largely manual attendance workflow with an automated, contactless process. The prototype brought together image collection, model training, real-time recognition, attendance validation, digital record keeping, and a browser-based interface in one system. Students do not need a manual register or a physical biometric device.

Limitations observed

FactorEffect on the system
Lighting conditionsCan reduce recognition accuracy
Dataset qualityPoor or too few images weaken the model
Camera qualityLow-resolution input affects detection and matching
Controlled prototype settingResults may not carry over to crowded, real-world rooms
Possible next steps (suggested, not part of the original project): add a database in place of CSV files, test with a larger and more varied dataset, and add liveness detection to reduce spoofing with photos.

Final takeaway

The Face Recognition Attendance System is a practical use of AI and computer vision for a repetitive administrative task. By combining OpenCV, LBPH, Flask, and digital storage, it turns registration, recognition, and record keeping into a single workflow. The result is a working prototype that reduces manual effort in an everyday institutional process.
